# VIDA Mobile

**VIDA Mobile** é um aplicativo multiplataforma projetado para impulsionar produtividade, bem-estar emocional e conexões sociais saudáveis. Construído com **React Native**, integração com **IA (Google Gemini)** e um sistema de **gamificação inteligente**, o app combina tecnologia e design minimalista para ajudar o usuário a viver de forma equilibrada, organizada e com intenção.

---

## 📌 Visão Geral

VIDA não é apenas um app de rotina — é um **ecossistema completo de organização pessoal**, assistente inteligente e social leve. Cada parte do produto segue três pilares fundamentais:

### 🔹 **Produtividade leve**

Uma rotina clara, visual e dividida por períodos do dia.

### 🔹 **Bem-estar genuíno**

Suporte emocional privado e insights diários gerados por IA.

### 🔹 **Social saudável**

Nada de seguidores, likes ou feed infinito. Apenas presença real.

A identidade visual utiliza tons de azul claro, especialmente o **#0052e2**, com estética minimalista, cards fluidos e animações sutis.

---

## 🧠 Inteligência Artificial Integrada

A IA atua como co-piloto do usuário, oferecendo:

* Sugestões de rotina baseadas em hábitos
* Priorização de tarefas inteligentes
* Análises de humor e diário emocional (privado)
* Geração de planejamento semanal
* Recomendações contextuais

---

## 🧩 Funcionalidades do APP

### 📅 **Rotina e Tarefas Inteligentes**

* Cards por períodos do dia (manhã, tarde, noite)
* Criação rápida com IA
* Tarefas com prioridades dinâmicas
* Pomodoro integrado
* Notificações inteligentes

### 🤖 **Assistente VIDA (IA)**

* Respostas rápidas
* Suporte emocional
* Sugestões personalizadas
* Planejamento guiado por IA

### 🙌 **Social Saudável**

* Um único **Momento do Dia** por usuário
* Amigos adicionados via NFC/QR Code
* Reações com emojis (sem curtidas públicas)
* Sem seguidores, sem contadores

### 🎖 **Gamificação**

* XP diário
* Streak saudável (sem punições extremas)
* Selos de consistência
* Desafios amigáveis

---

## 🏗️ Arquitetura e Stack

### **Frontend**

* React Native + Expo
* TypeScript
* Zustand / Context API
* Tailwind RN para estilização
* Reanimated / Moti para animações
* React Navigation

### **Backend**

* Node.js + Express
* PostgreSQL
* Prisma ORM
* JWT + Refresh Token
* Storage para imagens
* Push Notifications

### **IA**

* Google Gemini API
* Serviços orquestrados no backend
